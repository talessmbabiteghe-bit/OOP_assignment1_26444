# AUCA_26444 — Tax Administration Management System

## Open in VS Code
1. Extract `AUCA_26444.zip`.
2. Open the extracted `AUCA_26444` folder in Visual Studio Code.
3. Install the **Extension Pack for Java** if VS Code asks.
4. Open `src/com/auca/main/Main.java`.
5. Click **Run** above `main`, or compile from a terminal:

```bash
javac -d bin $(find src -name "*.java")
java -cp bin com.auca.main.Main
```

On Windows PowerShell, use the VS Code Run button or compile with the Java extension.

Student ID: 26444

## Important
This is a teaching simulation using fictional rates. It uses fixed-size arrays and one shared Scanner, not ArrayList or other collection classes. Dates must be entered as `YYYY-MM-DD`. Money is represented with `BigDecimal`.
